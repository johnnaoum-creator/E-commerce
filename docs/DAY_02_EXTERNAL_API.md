# Day 02 – External API Integration

## إحنا عملنا إيه النهارده؟

بعد ما خلصنا في اليوم الأول فحص ملفات Olist ومراجعة جودة البيانات، بدأنا نضيف مصدر بيانات خارجي للمشروع.

اخترنا **World Bank API** عشان نجيب شوية بيانات اقتصادية عن البرازيل، ونستخدمها بعد كده كبيانات إضافية جنب بيانات Olist.

## 1. مصدر البيانات

استخدمنا World Bank API، وده مصدر مفتوح بيقدم بيانات اقتصادية وإحصائيات عن دول العالم، ومش محتاج API Key للطلبات اللي استخدمناها.

الدولة اللي اشتغلنا عليها: Brazil (BR).

السنوات: من 2016 لـ 2018، عشان تتوافق مع الفترة اللي بيانات Olist بتغطيها.

## 2. البيانات اللي سحبناها

استخدمنا 3 مؤشرات:

- **Population:** عدد السكان.
- **GDP:** الناتج المحلي الإجمالي بالدولار الأمريكي الحالي.
- **Inflation:** معدل التضخم السنوي.

## 3. سحب البيانات وتخزينها (Extraction)

كتبنا Python Script اسمه:

`src/extract_world_bank.py`

واستخدمنا مكتبة `requests` عشان نتصل بالـ API ونسحب البيانات.

بعد كده حفظنا البيانات الأصلية زي ما رجعت من المصدر في ملفات JSON، من غير ما نغيّر فيها.

الملفات اتحفظت في:

`data/raw/external/`

وهي:

- `brazil_population_2016_2018.json`
- `brazil_gdp_2016_2018.json`
- `brazil_inflation_2016_2018.json`

## 4. تجهيز البيانات (Transformation)

بعد ما سحبنا البيانات، بدأنا نجهزها للاستخدام.

كتبنا Script تاني اسمه:

`src/transform_world_bank.py`

واللي عملناه فيه:

1. قرأنا ملفات JSON التلاتة.
2. استخرجنا البيانات الفعلية من كل ملف.
3. رتبنا البيانات وربطنا المؤشرات ببعض باستخدام السنة.
4. جمعنا كل المؤشرات في جدول واحد.

## 5. الناتج النهائي

حفظنا البيانات بعد تجهيزها في ملف CSV اسمه:

`world_bank_brazil_economic_data.csv`

وموجود في:

`data/processed/`

الملف فيه الأعمدة دي:

- `year`
- `population`
- `gdp`
- `inflation`

وبكده بقينا عندنا ملف واحد منظم فيه البيانات الاقتصادية التلاتة لكل سنة من 2016 لـ 2018.

## 6. هنستفيد من البيانات دي إزاي؟

البيانات دي هتكون مصدر إضافي نقدر نستخدمه جنب بيانات Olist.

ممكن بعد كده نجمع مبيعات Olist حسب السنة ونقارنها بالمؤشرات الاقتصادية لنفس السنة، عشان نضيف سياق اقتصادي للتحليل.

بس لازم ناخد بالنا إن بيانات Olist في 2016 و2018 مش بتغطي السنة كاملة، وإن المؤشرات الاقتصادية سنوية؛ فالمقارنة محتاجة تراعي الفرق ده، ومش معناها إن المؤشرات الاقتصادية هي سبب زيادة أو انخفاض المبيعات.

## 7. الملفات اللي اتضافت للمشروع

```text
src/
├── extract_world_bank.py
└── transform_world_bank.py

data/
├── raw/
│   └── external/
│       ├── brazil_population_2016_2018.json
│       ├── brazil_gdp_2016_2018.json
│       └── brazil_inflation_2016_2018.json
│
└── processed/
    └── world_bank_brazil_economic_data.csv
```
